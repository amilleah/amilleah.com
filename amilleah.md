# who am i

Hi! I'm Amilleah Rodriguez. I'm <!-- who-am-i -->.

I study how the brain constructs meaning during real-time language comprehension. I focus on prediction, surprisal, and composition in language processing. I also investigate the limits of existing language models, showing how they [fail to represent compositional meaning](https://aclanthology.org/2024.lrec-main.472/).

I earned a BA in Language and Mind from New York University working with Prof. Liina Pylkkänen. I will join the University of Michigan Linguistics PhD program in Fall 2026 as a Rackham Merit Fellow, where I'll be working with Prof. Jon Brennan in the [Computational Neurolinguistics Lab](https://cnllab.github.io).

## colophon

This site is created in part by [file.gallery](https://github.com/inchkev/file-gallery) made by [Kevin](https://kevin.garden), which indexes the spatial layout of files using `.DS_Store` metadata. You'll see the source code has a `.gardenignore`. I interpreted the spatial layout as a file tree for navigation while still maintaining the "simple" layout of previous iterations of this site.

Every folder has a Markdown file with the same name that acts as a landing page (inspired by the [Folder Notes](https://github.com/LostPaul/obsidian-folder-notes) plugin for Obsidian).

The site is basic Markdown compiled into HTML using [pnpm](https://pnpm.io) and Kevin's `cultivate` function, with some added flair to include my existing projects. This flair makes it somewhat heavy with JS, and I hope to improve this over time. This is "good enough" for now.

The site is still hosted with [Netlify](https://www.netlify.com/). 

The color palette is [uchū](https://uchu.style/), with a red-orange ([#df4a15](https://www.are.na/amilleah/df4a16)) for links.
