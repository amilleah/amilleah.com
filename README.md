# about me

Hi! I'm Amilleah Rodriguez.

I'm a researcher studying how the brain builds meaning during language comprehension. I'm currently working with prediction surprisal and probability to address how context is used while processing new information. I also work with language models, describing their compositional and representational capacities.

Previously at NYU's Neuroscience of Language Lab with Liina Pylkkänen; currently a Linguistics PhD student at the University of Michigan's [Computational Neurolinguistics Lab](https://cnllab.github.io/) with Jon Brennan.

- [developer for a cat-themed tactical RPG](https://clangen.io)

- [newsletter writer](https://amilleah.substack.com)
